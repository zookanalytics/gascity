# The arch check in this repository

This repository's architecture document is `engdocs/architecture.md`. Read
it wherever the arch method names `docs/architecture.md`: before the diff,
as the precondition of approval, and as the document that a change moving
the architecture updates in the same pull request. `docs/` is the published
documentation site, so the architecture document lives with the engineering
docs in `engdocs/`.

File a follow-up about that document under the method's tokens as they
stand, `docs/architecture.md: incomplete` and `docs/architecture.md: off the
standard`, so a later review finds the bead already filed.
